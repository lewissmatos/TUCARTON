# Test Boundaries

- `unit/` contains framework-independent domain and validation tests.
- `api/` contains HTTP/API integration tests once API modules exist.
- `mobile/` contains mobile UI and repository tests once flows exist.
- `offline/` contains deterministic outbox, synchronization, conflict, and QR protocol scenarios once those specifications are approved.

The foundation runs Vitest with no feature tests yet. Placeholder directories document ownership without pretending that product behavior is covered.
